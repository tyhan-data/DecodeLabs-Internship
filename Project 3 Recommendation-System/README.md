# 📚 Book Recommendation System

A Machine Learning-based Book Recommendation System that helps users discover books based on popularity and reading preferences. This project implements **Popularity-Based Filtering** and **Collaborative Filtering** to generate relevant book recommendations.

## 🚀 Features

- **Popularity-Based Recommendation:** Recommends popular books based on the number of ratings and average ratings.
- **Collaborative Filtering:** Recommends similar books based on user-rating patterns.
- **Cosine Similarity:** Measures similarity between books using rating-based representations.
- **Personalized Recommendations:** Suggests books based on relationships learned from user preferences.

## 🛠️ Technologies Used

- Python
- Pandas & NumPy
- Scikit-learn
- Matplotlib & Seaborn
- Jupyter Notebook
